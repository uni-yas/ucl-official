六角格子

六角格子のすべての地点を見分けるには、どれだけセンサーが必要か？

An improved lower bound for identifying codes in the hexagonal grid via a strict local-to-global relaxation gap

Yasuhito Tsujimura

検証資料を見る（Zenodo）↗
概要詳細公開資料

概要

六角格子にセンサーを置き、各地点が自分自身と隣接地点のどのセンサーに接しているかで、すべての地点を見分ける問題です。どのような配置でも必要となるセンサー密度の下限を改善しました。

詳細

無限六角格子の任意の識別コードについて、すべての中心における球密度の下極限が18/43 + 1/79310以上であることを証明しました。周期性を仮定しません。平面全体の最小密度の厳密値は未決です。
