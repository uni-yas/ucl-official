六角格子4.6.12格子
格子とセンサー配置 / 六角格子

近くで最も効率のよい配置を、平面全体に広げられるか？

An improved lower bound for identifying codes in the hexagonal grid via a strict local-to-global relaxation gap

Yasuhito Tsujimura · プレプリント（arXiv投稿済み・公開待ち）

論文PDF ↗引用情報検証資料
概要専門解説結果の範囲引用資料研究相談

概要

六角格子の各地点を、近くのセンサーの反応だけで見分ける問題です。七つの面だけを調べたときの理想的な密度は18/43。ところが、局所的な最適解に現れる模様をすべて集めても、平面全体をつなげません。

専門解説

七面の周辺分布を整合させた線形緩和を厳密に解き、全最適解が使い得る1,206種類の向き付き配置を特定しました。別の半径15の障害を平均することで、任意の識別コードの下極限密度に18/43 + 1/79310という下界を得ます。

結果の範囲

非周期配置も含む下界です。平面での最小密度の厳密値は未決です。

引用

Yasuhito Tsujimura. “An improved lower bound for identifying codes in the hexagonal grid via a strict local-to-global relaxation gap.” Manuscript.
