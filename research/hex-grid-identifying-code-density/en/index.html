Hexagonal grid

How many sensors are needed to distinguish every location in a hexagonal grid?

An improved lower bound for identifying codes in the hexagonal grid via a strict local-to-global relaxation gap

Yasuhito Tsujimura

View verification materials on Zenodo↗
OverviewDetailsPublic materials

Overview

Place sensors on a hexagonal grid so that every vertex is distinguished by the sensors at that vertex and its neighbors. This study improves the density lower bound that every identifying placement must satisfy.

Details

For every identifying code in the infinite hexagonal grid, the lower limiting graph-ball density at every center is at least 18/43 + 1/79310. No periodicity is assumed. The exact minimum density on the plane remains open.
