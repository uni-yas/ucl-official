Exact repair trade-offs for structured observation failures in a three-dimensional majority rule

Yasuhito Tsujimura

Universion Closure Logic · ORCID ↗

Public version: 2026-11-11Version 1.1.0English

Read full paper (PDF)Paper & verification record ↗Cite this paper

Abstract

On a finite periodic three-dimensional lattice, we study one synchronous majority update with threshold 14 on each 27-site neighborhood, including its center. We fix an observation mask for a reference configuration with two flat phases. The mask certifies the update if every completion of the unobserved bits gives the prescribed output at every site. For each admissible finite nonempty index set J, observations fail on translates of a fixed five-site tile along one coordinate direction. A repair may add or remove observed sites only within Chebyshev distance two of the failures. Failed sites remain unavailable, and all observations have their reference values.

Let k = |J|, let h count successive index differences equal to two, and let c count clusters formed by joining successive indices at distance at most two. Relative to the pre-failure mask, a additions and d deletions give a net increase of Δ = a − d observations and an edit count of e = a + d. We prove that the complete Pareto frontier consists of the h + 1 cost triples (Δ, e, a) = (4k + h + c − t, 14k + h + c + t, 9k + h + c), t = 0, …, h. Integer budget caps are jointly feasible exactly when at least one of these triples lies within all three caps. We bound acquisitions by counting which overlapping majority neighborhoods can use the same newly observed site. Given the tile positions in J, we construct a repair attaining each triple. Thus the three counts (k, h, c) suffice to decide feasibility.

What this result provides

An exact joint repair-budget frontier determined by three gap statistics.

Scope

The specified five-site failure family, reference mask, majority update and repair region. No formula for arbitrary failures is asserted.
