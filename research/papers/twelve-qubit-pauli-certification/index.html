Certifying a Twelve-Qubit State from the Same Pauli Measurement Record

Yasuhito Tsujimura

Universion Closure Logic · ORCID ↗

Public version: 2026-11-21Version 1.13English

Abstract

Exact two-site marginals determine the twelve-qubit target studied here. How often can finite pair counts certify full trace-norm error at most 0.1? We consider independent preparations, independent uniform local Pauli bases and ideal readout. Each prespecified rule has at least 95% coverage for every fixed twelve-qubit state. A matrix inequality combines a signed pair correlation with the absence of a forbidden outcome. For 10⁹ preparations of the ideal target, the probability that this rule certifies the state while a physical region built from separate Bernstein intervals for 630 Pauli coordinates abstains is at least 0.818644. Both use the same stored pair counts. Weighted witness compression accepts every record the matrix rule accepts at this budget. Both certify more than 99.7% of ideal records, and their acceptance probabilities differ by less than 0.0297 percentage points. If the all-ones state replaces the target with probability 10⁻⁸ per shot, the full trace-norm error is 2 × 10⁻⁸. A three-site energy rule then certifies the state while the matrix rule abstains with probability at least 0.998776. A rule allowing positive pair counts certifies this mixture with probability between 0.050696 and 0.051038 at the same budget. Its acceptance probability tends to one as the number of shots grows.

What this result provides

A finite-sample comparison of specified certification rules that use the same saved Pauli pair counts.

Scope

A particular twelve-qubit target, uniform local Pauli sampling, ideal readout and the stated statistical guarantees. The comparison is not against every possible certification method.
